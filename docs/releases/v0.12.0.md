# Traverse v0.12.0

Released 2026-09-16.

Traverse v0.12.0 is a **minor** lockstep crate + npm release. Its throughline
is *governed exact-ref local model execution*: Spec
`138-governed-exact-model-execution` lands the host-staged
`traverse.model-runtime` / `model.execute` path (native + browser wasm-cpu)
that merged after the `v0.11.0` publish cut (#1438).

## Highlights

### Exact-ref `model.execute` (Spec 138 / ADR-0074)

- Host-owned package store, single-consume staged I/O refs, and fail-closed
  policy / pin / digest checks behind Spec 137 `model.execute`.
- CPU-WASM guest ABI (`model_execute` + LE feature frames) with the echo
  fixture under `fixtures/models/fixture-echo-1.0.0/`.
- `traverse-embedder-web` exports matching stage / execute / read helpers so
  browser hosts share the same envelope contract as native
  `ExactModelHostConnector`.
- Connector contract `traverse.model-runtime` **2.0.0**; Specs 044 / 045 / 137
  amended for exact pins and authority-free payloads.

### Docs

- [docs/exact-ref-model-execution.md](../exact-ref-model-execution.md)

## Upgrade notes

- Apps that want local exact-ref models must declare
  `exact_model_dependencies` (Spec 044) and use `model_ref` digests that match
  pins — provider authority fields on `model.execute` payloads fail closed.
- Pin `traverse-embedder-web@0.12.0` together with crates at `0.12.0`
  (lockstep, Decision 85).
- Certified `runtime.wasm` digest is unchanged from `0.11.0`; no new
  `runtime/native-runtime-registry.json` row is required for this cut.

## Validation

Release preparation must pass these local gates before tagging:

```bash
cargo build --workspace
cargo test -p traverse-runtime --lib exact_model
bash scripts/ci/repository_checks.sh
bash scripts/ci/spec_alignment_check.sh
```

The tagged commit must pass the GitHub `version-guard`, `repository-checks`,
`coverage-gate`, and related required jobs before tag-triggered crates.io /
npm publish.

## Release steps

Per [the release process](https://github.com/traverse-framework/traverse/blob/main/docs/release-process.md), from a clean `main`
checkout after CI is green:

```bash
bash scripts/ci/bump_version.sh 0.12.0
git push origin main
git push origin v0.12.0
git push origin web-v0.12.0
```

Then complete the post-cut docs / website checklist in
[the release process](https://github.com/traverse-framework/traverse/blob/main/docs/release-process.md#post-cut-documentation-readmes-and-website).
